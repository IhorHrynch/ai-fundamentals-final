# Simple Regression Model Prediction

Веб-додаток для передбачення значень за допомогою лінійної регресії. Користувач задає ознаку (slider −3…3), отримує передбачення та візуалізацію порівняння з фактичними даними з навчального набору.

## Стек

- **Python** — основний код
- **scikit-learn** — лінійна регресія, генерація даних, метрики
- **Streamlit** — веб-інтерфейс
- **joblib** — збереження/завантаження моделі та даних
- **NumPy** — робота з масивами
- **Matplotlib** — графіки

## Структура проєкту

```
Final Project/
├── app.py                      # Streamlit-додаток (передбачення + візуалізація)
├── model.py                    # Навчання, збереження моделі та датасетів
├── linear_regression_model.joblib   # Збережена модель (після запуску model.py)
├── X.joblib                    # Ознаки датасету (після model.py)
├── y.joblib                    # Цільові значення (після model.py)
├── requirements.txt
├── .gitignore
└── README.md
```

## Навчання моделі

Перед першим запуском додатку потрібно натренувати модель та зберегти дані:

```bash
python model.py
```

Скрипт:

- генерує синтетичний датасет (`make_regression`, 100 зразків, 1 ознака, шум 20);
- масштабує ознаку до діапазону −3…3;
- ділить дані на train/test (80/20);
- тренує `LinearRegression`;
- виводить MSE на тесті;
- зберігає модель у `linear_regression_model.joblib`;
- зберігає повні X та y у `X.joblib` та `y.joblib`.

Після цього у каталозі з’являться файли: `linear_regression_model.joblib`, `X.joblib`, `y.joblib`.

## Запуск додатку

```bash
streamlit run app.py
```

У браузері відкриється інтерфейс:

- **Slider** — вибір значення ознаки (від −3 до 3).
- **Predict value** — кнопка передбачення.
- Під кнопкою — передбачене значення та графік: сірий scatter (датасет), синя точка (фактичне значення для найближчого X), червона точка (передбачення), пунктирна лінія та підпис із різницею.

## Використання

1. Запустити `model.py` один раз (або після зміни даних/параметрів).
2. Запустити `streamlit run app.py`.
3. Рухати слайдер і натискати «Predict value» для перегляду передбачень та порівняння з даними.

## Примітки

- Модель та датасети (`*.joblib`) краще додати в `.gitignore`, якщо не хочете їх комітити (вони генеруються командою `python model.py`).
- Для зміни кількості зразків, шуму або `random_state` потрібно змінити параметри в `model.py` і знову запустити `python model.py`.
